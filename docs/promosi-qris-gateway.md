# Teks Promosi — QRIS Gateway Arta Pedia

Semua angka di berkas ini diambil dari `lib/gatewayConfig.js`. Kalau angkanya
diubah di sana, teks di sini WAJIB ikut diperbarui — promo yang menyebut biaya
lama akan dibaca sebagai janji, dan orang yang merasa ditipu soal Rp250 tidak
akan kembali untuk hal yang lebih besar.

| Hal | Nilai |
|---|---|
| Tagihan minimum | Rp2.000 |
| Tagihan maksimum | Rp10.000.000 |
| Biaya per tagihan dibayar | Rp250 |
| Tarik ke e-wallet, minimum | Rp5.000 |
| Biaya penarikan | Rp1.000 |
| Konversi ke saldo Arta Pedia | min Rp1.000, tanpa biaya |
| E-wallet didukung | DANA, OVO, GoPay, ShopeePay, LinkAja |
| Penarikan | **manual**, dicek admin dulu |

Tiga hal yang TIDAK boleh ditulis di promo, karena tidak benar:

1. **"Penarikan instan/otomatis."** Penarikan diperiksa admin dulu. Menjanjikan
   instan lalu orang menunggu berjam-jam adalah keluhan pertama yang akan masuk.
2. **"Anonim"** atau **"tidak bisa dilacak"**. Yang benar: tidak perlu unggah
   KTP dan tidak perlu berkas usaha untuk MULAI. Mutasinya tetap tercatat penuh,
   dan akun yang dipakai menipu tetap dibekukan — itu memang ada di syarat
   ketentuannya.
3. **Jumlah pengguna, testimoni, atau "dipakai 1.000+ seller."** Tidak ada
   datanya. Angka karangan di promo adalah utang yang ditagih saat ada yang
   bertanya.

## 4. Untuk developer / pemilik bot

```
🔑 QRIS GATEWAY API — ARTA PEDIA
Payment gateway QRIS tanpa berkas usaha, buat bot & website kamu.

📍 Base URL
   https://artapedianokosmurahid.vercel.app/api/gw/v1

🔐 Auth
   Header: X-API-Key: apk_xxxxx

📮 Endpoint
   POST /invoice          → bikin tagihan QRIS
   GET  /invoice/{id}     → cek status (pending/paid/expired)
   📡 Callback            → kami POST ke URL kamu saat dibayar

📦 Contoh kode siap tempel
   🐍 Python  ·  🟢 Node.js  ·  🐘 PHP  ·  ⚡ cURL

💰 Batas & biaya
   Rp2.000 – Rp10.000.000 per tagihan
   Rp250 per tagihan DIBAYAR (bukan per tagihan dibuat)
   Tarik: min Rp5.000, fee Rp1.000, ke 5 e-wallet
   Konversi ke saldo nokos: min Rp1.000, gratis

⚠️ Satu hal yang kami tulis di doc-nya sendiri:
   JANGAN percaya isi callback mentah-mentah. Endpoint callback
   kamu terbuka di internet, siapa pun yang tahu URL-nya bisa
   kirim {"status":"paid"} palsu. Selalu panggil balik
   GET /invoice/{id} buat mastiin sebelum ngasih barang.
   Kami nulis peringatan ini karena lebih milih kamu aman
   daripada integrasinya kelihatan gampang. 🛡️

🚀 Ambil API key-nya di dasbor QRIS Gateway.
```
